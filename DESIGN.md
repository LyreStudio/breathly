# Breathly design

This source fork retains the upstream guided-breathing design and MPL-2.0 terms. The breathing animation remains the focus. Read theme colors, typography and spacing from `src/design`; preserve the separate Android, iOS and web settings owners and their parity tests.

The October 16 upstream update widens the Android exercise-time value so two digits remain visible and supplies an Android monochrome launcher icon. It changes neither the theme system nor the app's branding. The icon and modified source retain the upstream licence and notices.

The screenshot in `screenshots/mobile.png` is attributed historical upstream artwork. It is not an installed-device capture of this update. Native rendering, themed-launcher behavior and Maestro flow acceptance remain pending; local JavaScript exports and component assertions have narrower scope.
